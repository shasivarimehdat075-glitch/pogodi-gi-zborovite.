# Погоди ги зборовите — Android прототип

Овој проект е почетен Godot 4 офлајн прототип на македонски јазик.

## APK без компјутер (преку телефон и GitHub Actions)

Потребна е интернет-врска и бесплатна GitHub сметка. GitHub ќе ја изврши компилацијата во cloud; телефонот служи за поставување и преземање.

1. Преземи го ZIP-от и отпакувај го во телефонот.
2. Во Chrome отвори https://github.com и направи бесплатна сметка / најави се.
3. Создади нов public repository со име `pogodi-gi-zborovite`.
4. Избери **Add file > Upload files** и постави ги сите датотеки и папки од проектот, вклучувајќи `.github` и `export_presets.cfg`. Ако мобилниот преглед не прикажува скриени папки, користи GitHub Desktop на компјутер или друг начин за поставување на `.github/workflows/android-apk.yml`.
5. Commit changes во гранката `main`.
6. Отвори го табот **Actions** во репозиториумот. Избери **Build Android APK** и притисни **Run workflow** ако не почнало автоматски.
7. Кога ќе заврши успешно, отвори го завршениот workflow run, најди **Artifacts** и преземи `PogodiGiZborovite-Android-APK`.
8. Отпакувај го artifact ZIP-от на телефонот. Допрете `PogodiGiZborovite-debug.apk` и дозволи инсталација од тој извор ако Android побара.

## Важно
- Ова е debug APK за тестирање, не е финална верзија за Google Play.
- Проектот моментално е офлајн 2D интерфејс-прототип. Не се имплементирани вистинска 3D сцена, онлајн мултиплеер, кориснички сметки или сервер.
- GitHub Actions извршува компилација во cloud. Овој процес не е целосно без чекори: треба да поставиш проект и да ја преземеш APK датотеката.
- Ако GitHub workflow не успее, испрати ми screenshot или логот од грешката за да го поправиме.
