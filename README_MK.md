# Погоди ги зборовите — Godot 4 проект

## Што содржи првата верзија
- Македонски интерфејс
- Три начини на игра: измешани букви, асоцијации и логички траги
- Поени и тајмер
- Случаен редослед на прашањата
- Почетен офлајн прототип

## Како да го отвориш
1. Инсталирај Godot Engine 4.x.
2. Отвори го Godot Project Manager.
3. Избери Import и посочи го `project.godot`.
4. Притисни Run (F6/F6 или F6 според верзијата).

## Android APK
За APK export е потребен Godot Android export template, Android SDK и Java JDK.
Во Godot отвори Editor > Manage Export Templates, инсталирај шаблони, а потоа Project > Export > Add Android.
Постави package ID, на пример `com.pogodigizborovite.game`, и извези APK.

## Следни фази
1. Подобрување на играта со 3D сцена, материјали, светла и анимации.
2. Повеќе македонски зборови, категории и тежини.
3. Мултиплеер сервер со соби, покани и синхронизирани рунди.
4. Профили, рангирање и безбедно чување на резултати.

Забелешка: ова е почетен офлајн прототип. Онлајн мултиплеерот и финалните 3D ресурси сè уште не се имплементирани.
